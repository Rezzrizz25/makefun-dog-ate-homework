A make.fun entry for "The Dog Ate My Homework: Funniest Excuse" — a single line, in the dog's own voice, explaining why the homework got eaten. The dog is not sorry. The homework started it.

> Look, the homework looked at me first. It sat there all week whispering 'chew me' in pencil, so I did my duty as a dog.

## Run it

```sh
node main.ts && cat /output/entry.txt
```

`main.ts` writes the 119-character entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and throws if the 1–200 character gate is violated.
